# SkillBridge AI

SkillBridge AI is an all-domain career and skill development web application.

It helps users from 10th pass to postgraduate level identify suitable career options, required skills, skill gaps, recommended courses, and personalized learning paths.

## Main Features

- User Registration and Login
- Education Level Selection
- Career Domain Selection
- Target Company Selection
- Target Job Selection
- Skill Assessment
- Skill Gap Analysis
- Skill Recommendations
- Course Recommendations
- Personalized Learning Path
- Progress Dashboard
